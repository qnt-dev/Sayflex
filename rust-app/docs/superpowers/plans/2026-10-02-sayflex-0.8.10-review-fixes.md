# SayFlex 0.8.10 — fixes agreed in the 0.8.9 review

Source: three review rounds on 2026-10-02 (two independent reviewers, every
mechanism re-verified against code, logs and git history). Baseline is commit
`d387dbd`, the exact source of the installed 0.8.9 local repair.

Each item has a type, because evidence and the definition of "done" differ:

- **B** — behaviour defect (wrong result, lost work, false confirmation)
- **S** — security / privacy defect
- **U** — interface defect (unreadable, unreachable or misleading UI)
- **R** — release / delivery gate
- **P** — performance (measure first, then change)

Status: `todo` · `done` · `blocked (reason)` · `deferred (needs user decision)`.

## 7. Not in scope (recorded so they are not lost)

- `site_url` is never collected (capability limitation; reading browser URLs is a privacy decision).
- English chips on the result toolbar and 8–9 px labels are part of the agreed visual design; changing them needs the user's design call.
- Result window does not relayout on manual resize — fixed overlay coordinates are intentional for on-image alignment.
- Unverified clipboard insertions (8–12 % recently) are a confirmation/latency issue, not measured text loss; needs a separate investigation.
