# SayFlex 0.8.2 Regression Release Specification

## Outcome

Ship and install SayFlex 0.8.2 as an in-place upgrade over 0.8.1. The release
must correct the two runtime regressions observed on September 25, 2026 without
weakening clipboard preservation or the progressive translation-card animation.

## Required behavior

1. Automatic dictation insertion and clipboard-based selection capture must
   continue when the clipboard advertises a private format that cannot be
   materialized, provided at least one advertised format can be copied.
2. Readable standard image formats must still be restored after insertion, and
   a non-empty clipboard for which no format can be preserved must fail safely
   instead of being cleared. Failure to duplicate a materialized format must
   abort the complete snapshot rather than silently produce a partial backup.
3. The same clipboard policy must cover WezTerm's `Ctrl+Insert` selection-copy
   fallback; there must not be a separate terminal-only workaround.
4. A short translation result must paint the full minimum-height native popup.
   Progressive paragraph publication and smooth growth for larger cards remain.
5. User settings, history, downloaded models, and runtimes must survive the
   installer upgrade.

## Release gates

- New regression tests must be observed failing before production changes and
  passing afterward.
- `cargo test --workspace`, formatting, linting, release build validation, and
  installer checksum validation must pass on the final tree.
- The new installer must be installed over 0.8.1; 0.8.1 must not be uninstalled
  first.
- Installed executables and registration must report 0.8.2 before the new
  SayFlex process is launched.
