# SayFlex 0.8.0 Model Lifecycle and UI Quality Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship one 0.8.0 candidate with safe local-model removal, truthful memory state, reliable hotkeys, native-quality localized UI, Companion help, and a redesigned standalone translator.

**Architecture:** Worker processes remain authoritative for model lifecycle and report completion over the versioned protocol; the Slint desktop projects acknowledged state. UI work reuses the existing sheet and typed localization layer, while protocol and model-manager tests protect destructive boundaries.

**Tech Stack:** Rust 2024 workspace, Slint 1.17, Win32 hotkeys, whisper-rs, llama.cpp child process, serde JSON-lines, Inno Setup, PowerShell/Pester.

**Spec:** `docs/superpowers/specs/2026-09-11-sayflex-0.8.0-model-lifecycle-and-ui-quality-design.md`

## Global Constraints

- Windows 10/11 x64 only.
- Interface locales are System, English, Russian, Ukrainian, Spanish, Brazilian Portuguese, German, French, Italian, and Korean.
- Never delete history, credentials, settings, or any path not derived from a validated catalog descriptor under its configured root.
- Do not claim exact VRAM bytes; acknowledge only that the model engine was dropped.
- Build, package, install, and smoke-test one candidate after all source gates pass.
- Do not call an unsigned or user-unverified artifact public-ready.
